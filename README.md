# Groove-Music 🎵

A premium, glassmorphic music streaming platform built with React, Node.js, and MongoDB.

## Features
- **Global Music Search**: Search for any track via the iTunes API.
- **Direct Streaming**: High-quality audio streaming powered by YouTube.
- **Personalized Experience**: Like tracks and create custom playlists.
- **Modern UI**: Sleek, responsive design with glassmorphic aesthetics.
- **Secure Auth**: Seamless Google OAuth integration.

## Project Structure
```text
├── backend/        # Express server & API
├── frontend/       # React application
└── .planning/      # Project management & roadmap
```

## Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB
- Python (for yt-dlp)

### Backend Setup
1. Navigate to `backend/`.
2. Install dependencies: `npm install`.
3. Create a `.env` file based on `.env.example`.
4. Start the server: `npm run dev`.

### Frontend Setup
1. Navigate to `frontend/`.
2. Install dependencies: `npm install`.
3. Start the dev server: `npm run dev`.
